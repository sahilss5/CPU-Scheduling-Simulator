First-Come, First-Served (FCFS)

Non-Preemptive

Processes are dispatched strictly according to their arrival time in the ready queue. The process that arrives first gets executed first until completion.

Advantages

  • Simple and easy to understand/implement
  • No starvation (every process eventually executes)

Disadvantages

  • High Average Waiting Time (Convoy Effect)
  • Poor performance for interactive time-sharing systems

Time Complexity

O(N log N) — due to sorting by arrival time

Suitable Use Cases

Batch processing systems where response time is not critical

Viva & Operating System Theory Reference Guide

Comprehensive theoretical reference, formulas, complexities, and top viva examination questions.

Operating System Metrics Formulas

Turnaround Time (TAT) TAT = Completion Time (CT) − Arrival Time (AT)
Waiting Time (WT) WT = Turnaround Time (TAT) − Burst Time (BT)
Response Time (RT) RT = Time of First Execution − Arrival Time (AT)
CPU Utilization % Utilization = (Total Busy CPU Time / Total Execution Time) × 100

Scheduling Policy Characteristics

  • FCFS: Non-preemptive, simple FIFO queue dispatching, subject to Convoy Effect.
  • SJF: Non-preemptive, picks smallest burst time available, provably optimal for minimum average waiting time.
  • SRTF: Preemptive SJF, preempts running process if a newly arrived process has shorter remaining time.
  • Priority NP: Non-preemptive, lower numerical value = higher priority rank.
  • Priority Preemptive: Preemptive, immediately preempts CPU if higher priority process arrives.
  • Round Robin: Preemptive, uses fixed Time Quantum slice to guarantee quick response time.

Top 15 Operating Systems Viva & Interview Questions

1. What is CPU Scheduling and why is it necessary?

CPU scheduling is the process by which the OS allocates CPU core execution time to ready processes. It maximizes CPU utilization, throughput, and guarantees fairness and responsiveness in multi-tasking systems.

2. What is the difference between Preemptive and Non-Preemptive scheduling?

In non-preemptive scheduling, once a process is allocated the CPU, it holds it until completion or I/O block. In preemptive scheduling, the OS can forcibly suspend a running process to allocate CPU to a higher priority or newly arrived process.

3. What is the Convoy Effect in FCFS?

The Convoy Effect occurs when short processes are delayed behind a very long CPU-bound process in a non-preemptive FCFS queue, causing high average waiting time.

4. Why is Shortest Job First (SJF) provably optimal?

SJF minimizes the total sum of waiting times by moving smaller bursts to the front of the queue, minimizing waiting delay for subsequent processes.

5. What is Starvation and how can Aging resolve it?

Starvation occurs when low priority processes are indefinitely postponed by a continuous stream of higher priority processes. Aging gradually increases the priority of long-waiting processes over time.

6. How does Time Quantum selection affect Round Robin performance?

If TQ is extremely large, RR degrades into FCFS. If TQ is extremely small, context switching overhead dominates CPU execution efficiency.

7. What is Context Switching and what is its overhead?

Context switching saves the execution state (registers, program counter) of a running process and restores another. Its overhead consists of CPU time spent solely on kernel state transitions without doing useful process work.

8. What is the difference between Turnaround Time (TAT) and Waiting Time (WT)?

Turnaround Time is the total elapsed time from arrival to completion (TAT = CT - AT). Waiting Time is the total duration a process spends waiting in the ready queue for CPU allocation (WT = TAT - BT).

9. What is Response Time (RT) and why is it crucial for interactive systems?

Response Time is the delay between process arrival and its very first CPU execution (RT = First Start Time - AT). Low response time ensures rapid feedback in interactive time-sharing environments.

10. How is CPU Utilization calculated and what does it measure?

CPU Utilization is the percentage of total time the CPU core spends executing non-idle process workload (CPU Util = [Busy Time / Total Time] * 100). Higher utilization reflects optimal hardware usage.

11. What is Throughput in CPU scheduling?

Throughput is the number of processes completed by the CPU per unit of time (Throughput = Completed Jobs / Total Time). Maximizing throughput increases system processing capacity.

12. What is Shortest Remaining Time First (SRTF)?

SRTF is the preemptive version of SJF. If a newly arrived process has a shorter remaining burst time than the currently executing process, the CPU is preempted immediately for the new process.

13. What is Priority Scheduling and how does Preemptive Priority differ from Non-Preemptive Priority?

Priority scheduling assigns numerical priority ranks to processes. In non-preemptive priority, running jobs finish undisturbed. In preemptive priority, an arriving higher-priority job immediately preempts the current process.

14. What is the Dispatcher and how does Dispatch Latency affect system performance?

The Dispatcher is the kernel module that transfers control of the CPU to the process chosen by the scheduler. Dispatch Latency is the time delay spent stopping one process and starting another.

15. What is Multilevel Queue (MLQ) and Multilevel Feedback Queue (MLFQ) scheduling?

MLQ partitions the ready queue into separate sub-queues with fixed priorities. MLFQ allows processes to move between queues based on CPU burst behavior, dynamic priority aging, and I/O feedback.
